# Publication Order or Series Order? A Practical Guide

Here are 4 authors and series where order matters, each with a start-here book and a link to the full list on [Books in Order](https://books.resuhive.com/). ## A simple way to choose

1. Pick the author whose first book sounds most like something you already enjoy.
2. Read the first book before you decide whether to commit to the whole list.
3. Use publication order unless the list says otherwise, because it is the order the author wrote.
4. Check for a next book. A dated release gives you a finish line.
